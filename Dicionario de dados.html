Dicionário de Dados Conceitual — Loja de Tintas e Materiais de Construção

Aviso: A estrutura abaixo foi atualizada de acordo com as boas práticas de documentação, separando as restrições em colunas independentes para Tipo de Variável, Valores Permitidos e Valores Nulos.

CATEGORIA

Atributo Descrição Tipo de Variável Valores Permitidos Valores Nulos Anotações
id_categoria Identificador único da categoria INT > 0 Não PK, Gerado automaticamente
nome_categoria Nome da categoria de produto VARCHAR(50) Qualquer texto Não Único

PRODUTO

Atributo Descrição Tipo de Variável Valores Permitidos Valores Nulos Anotações
id_produto Identificador único interno INT > 0 Não PK
codigo_barras Código de barras/EAN VARCHAR(14) 13 a 14 dígitos numéricos Sim Obrigatório
nome_produto Nome/descrição comercial do produto VARCHAR(150) Qualquer texto Não Obrigatório
preco Preço de venda vigente DECIMAL(10,2) ≥ 0 Não Obrigatório
id_categoria Categoria do produto INT > 0 Sim FK (Refere-se a CATEGORIA)

CLIENTE

Atributo Descrição Tipo de Variável Valores Permitidos Valores Nulos Anotações
id_cliente Identificador único INT > 0 Não PK
nome Nome do cliente ou razão social VARCHAR(150) Qualquer texto Não Obrigatório
cpf CPF do cliente pessoa física CHAR(11) 11 dígitos numéricos Sim Único
telefone Telefone de contato VARCHAR(15) Formato (XX) XXXXX-XXXX Sim Obrigatório
cnpj CNPJ da obra/empresa CHAR(14) 14 dígitos numéricos Não Único
razao_social Razão social da obra/empresa VARCHAR(150) Qualquer texto Não Obrigatório
endereco Endereço da obra/empresa VARCHAR(255) Qualquer texto Não Obrigatório
cep CEP do endereço da obra/empresa CHAR(8) 8 dígitos numéricos Não Obrigatório

FUNCIONARIO

Atributo Descrição Tipo de Variável Valores Permitidos Valores Nulos Anotações
id_funcionario Identificador único INT > 0 Não PK
nome_funcionario Nome do funcionário VARCHAR(150) Qualquer texto Não Obrigatório

VENDA

Atributo Descrição Tipo de Variável Valores Permitidos Valores Nulos Anotações
id_venda Identificador único INT > 0 Não PK
data_hora Data e hora da venda DATETIME Data e hora válidas Não Gerado automaticamente
id_cliente Cliente que realizou a compra INT > 0 Sim FK (Refere-se a CLIENTE)
id_funcionario Funcionário que realizou a venda INT > 0 Não FK (Refere-se a FUNCIONARIO)
valor_total Valor total da venda DECIMAL(10,2) ≥ 0 Não Gerado automaticamente

ITEM_VENDA

Atributo Descrição Tipo de Variável Valores Permitidos Valores Nulos Anotações
id_item_venda Identificador único do item INT > 0 Não PK
id_venda Venda à qual pertence INT > 0 Não FK (Refere-se a VENDA)
id_produto Produto vendido INT > 0 Não FK (Refere-se a PRODUTO)
quantidade Quantidade vendida DECIMAL(8,3) > 0 Não Suporta números fracionados
preco_unitario Preço praticado na venda DECIMAL(10,2) ≥ 0 Não FK (Refere-se a PRECO)
subtotal Quantidade × preço unitário DECIMAL(10,2) ≥ 0 Não Calculado automaticamente

PAGAMENTO

Atributo Descrição Tipo de Variável Valores Permitidos Valores Nulos Anotações
id_pagamento Identificador único INT > 0 Não PK
id_venda Venda associada INT > 0 Não FK (Refere-se a VENDA)
forma_pagamento Forma utilizada no pagamento VARCHAR(50) 'Dinheiro', 'Pix', 'Cartão' Não FK (Refere-se a FORMA_PAGAMENTO)
valor_pago Valor pago DECIMAL(10,2) ≥ 0 Não FK (Refere-se a PAGAMENTO)
